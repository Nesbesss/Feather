# Bundled network blocklist

Feather's release snapshot uses **HaGeZi Multi LIGHT**, published under GPL-3.0.
The exact published domain list, upstream license and FAQ are retained here,
with immutable source URLs and SHA-256 hashes in `manifest.json`.

Upstream: [hagezi/dns-blocklists](https://github.com/hagezi/dns-blocklists),
commit `6782a0d55068c13b08c5d583395ccd4b3540a84e` (2026-10-28),
list version `2026.1028.0926.19`. The pinned FAQ's licensing section states that
the published lists use GPL-3.0. This input is the project's published list,
rather than a new assembly of its third-party input datasets.

The 73,103 published domain entries generate **73,103 WebKit rules**. This
replaces the previous StevenBlack aggregate snapshot (39,754 rules); it is a
different selection of domains, so counts do not establish equivalent blocking
or improved protection. Feather's existing third-party-only blocking policy,
subdomain matching and content-rule converter are unchanged. The two existing
cosmetic rules are Feather-authored and remain unchanged.

The adapter verifies the pinned files and prefixes each plain domain with
`0.0.0.0`. `BlocklistConverter.swift` performs existing normalization, subdomain
deduplication, sorting and WebKit JSON generation. No live updates occur in Feather.

From the repository root, using Python 3 and the Swift command-line tools:

```sh
Tools/make-blocklist.sh          # regenerate offline
Tools/make-blocklist.sh --check  # compare exact generated bytes offline
Tools/make-blocklist.sh --fetch --check  # restore only the same pinned inputs
```

To update deliberately, review a newer upstream commit and its license, replace
the snapshots, update input hashes and counts in `manifest.json`, generate with
the existing Swift converter, and record the new output hash. Review the result
and run blocking/website compatibility checks before shipping. The fetch option
never follows a moving `main` or `latest` URL.

The previous aggregate is retained only in ignored local release-prep backup
storage, outside the public source export and distribution.
